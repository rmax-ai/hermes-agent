# Scheduler recovery unit templates

These `.in` files are reviewable templates only. They are not installed, generated by the gateway
installer, or enabled by this change. Live automatic restart remains disabled until Max approves
the exact rendered unit diff.

After approval, render the placeholders from the gateway service already in use:

- `@PYTHON@`: its Python interpreter.
- `@PACKAGE_ROOT@`: its importable Hermes package root.
- `@HERMES_HOME@`: the gateway's active profile home.
- `@GATEWAY_UNIT@`: the gateway's exact systemd service unit name.
- `@APPROVAL_FILE@`: an operator-created approval marker.
- `@RECOVERY_SERVICE_UNIT@`: the rendered recovery service unit name.
- `@RECOVERY_TIMER_UNIT@`: the rendered recovery timer unit name.

Do not copy credentials or service environment files into these templates. The templates are not
installed or enabled, and a rendered service also requires the approval marker before it can request
a restart. It observes the unit every 30 seconds, requires two stale scheduler observations before
one restart request, waits through a three-minute grace when scheduler progress is missing,
limits automatic requests to five per rolling 24 hours, and leaves one restart slot outside its
automatic budget for the operator. A restart remains pending until a new PID/start-time/boot
identity has a startup banner and at least two successful scheduler ticks.

The observer treats a recent loop heartbeat or `systemctl` active state as insufficient proof of
recovery. Readiness reports cgroup v2 `memory.current`, `memory.high`, and `memory.events` when
available. Memory pressure degrades readiness and inhibits automatic restarts; the observer never
writes memory limits or tunes cgroups.

Activation is deliberately absent from this change. After the approval gate is cleared and the
rendered units have been reviewed, the timer can be enabled with the service manager's normal
`daemon-reload` and `enable --now` workflow. Roll back with:

```sh
systemctl --user disable --now @RECOVERY_TIMER_UNIT@
systemctl --user stop @RECOVERY_SERVICE_UNIT@
```
